Map interpretation guide for the forest pattern classification of the taiga-tundra ecotone

The forest pattern classification of the TTE uses tree cover and its abruptness. Abruptness compares how much tree cover changes across a 30 m pixel with how much cover the pixel has. To explore this classification scheme, choose a landscape, then select any pixel to see its arithmetic. Arrow keys move the selection.

Points to notice

    Transect

    The rate of change

    Calculated as a terrain slope, with cover (0 to 100) in place of elevation in metres. No real height is implied. It compares left with right and up with down, 60 m apart, and never uses the pixel itself. The angle is rescaled so 90° is 100; it tops out near 75.

    Abruptness

    (rate − cover) / (rate + cover), from −1 to +1. At 0 the rate equals the cover. Above +0.5 it is more than 3 times the cover; below −0.5, less than one third.

    Masked out

    Pixels with abruptness exactly 0 are masked, which removes treeless ground with no change around it. At the border of these grids the outer pixels are repeated, so every pixel has four neighbours.
