Circumpolar Taiga–Tundra Ecotone

Forest structure pattern across the taiga–tundra ecotone, mapped with the same method, but from two sources of tree canopy cover a decade apart. Differences in these maps are largely related to the data sources used, not temporal change. This map comparison is for open exploration of these differences.

Paul Montesano · NASA Goddard Space Flight Center / ESSIC, U. Maryland-College Park
